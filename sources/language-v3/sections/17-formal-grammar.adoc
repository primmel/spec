[[formal-grammar]]
== Formal grammar (EBNF)

This clause states the grammar of the language at its load-bearing levels:
the lexical structure, the top level, and the shared sub-structures that
recur across constructs. The per-construct facet grammars are specified in
<<subject-model,clauses 10>> to <<multilinguality,15>>, and the construct
registry in <<annex-a-constructs,Annex A>> states every
keyword, its aliases, and its payload shape. The grammar notation is EBNF:
`[ x ]` is optional, `{ x }` repeats zero or more times, and `|`
separates alternatives.

=== Lexical grammar

[source,ebnf]
----
Text        ::= { Whitespace | Comment | Token }
Whitespace  ::= ? any Unicode whitespace character ?
Comment     ::= ( '#' | '//' ) { ? any character except line feed ? } LineEnd
              (* recognized only at a token boundary *)
Token       ::= QuotedString | Block | BareToken
BareToken   ::= NonSpace { NonSpace }
            (* where the first character is neither '"' nor '{' *)
QuotedString::= '"' { EscapedChar | ? any character except unescaped '"' ? } '"'
EscapedChar ::= '\' ? any character ?
Block       ::= '{' Text '}'
            (* balanced; a quoted string inside a block is scanned as a
               string, so braces inside it do not nest *)
LineEnd     ::= ? line feed or end of input ?
----

=== Top-level grammar

[source,ebnf]
----
Model          ::= { Declaration }
Declaration    ::= SpecialDecl | ConstructDecl
SpecialDecl    ::= 'root' BareToken
                 | 'version' QuotedString
                 | 'metadata' Block
                 | 'package' Block
ConstructDecl  ::= Keyword Identifier Block
Keyword        ::= ? a keyword of Annex A, or an alias ?
Identifier     ::= BareToken
----

Within a block, the facet grammar of each construct is a sequence of
facet entries:

[source,ebnf]
----
FacetEntry   ::= FacetKeyword FacetValue
FacetKeyword ::= ? a facet keyword of the construct ?
FacetValue   ::= QuotedString | Block | BareToken | ExpressionCarrier | BracketList
ExpressionCarrier ::= ExpressionString | ExpressionBlock
ExpressionString  ::= ? a token starting with 'ocl{', re-accumulated until the
                   braces balance ? (* the legacy carrier; C178 deprecates *)
ExpressionBlock   ::= 'expression' Block | 'derive' Block | 'derivation' Block
                    | 'check' Block
(* The block's body is FIRST-CLASS EXPRESSION SYNTAX (<<expression-language>>):
   the precedence grammar below, harvested by the checker's identifier
   resolution — never a quoted string. The grammar applies no expression
   tokenization to the block: the body is the raw span the expression
   parser reads. *)
BracketList  ::= ? a token starting with '[', re-accumulated until the
                   accumulated text contains ']' ?
----

[[shared-sub-structures]]
=== Shared sub-structures

The provenance block, the typed relation, the key-value entry, the
quantity block, the trust reference, the correspondence entry, and the
alias list entry recur across constructs. The LML-aligned revision adds
the description block, the mapping block, the member-fields block, the
string-format block, and the namespace block:

[source,ebnf]
----
SourceBlock    ::= 'source' '{' 'doc' Value 'clause' Value [ 'fragment' Value ] '}'
RefEntry       ::= 'ref' Predicate Value [ '{' 'note' QuotedString '}' ]
Predicate      ::= BareToken   (* declared in a predicate registry; C103 *)
KeyValueEntry  ::= Key ':' Value [ Unit ]
                 | Key ':' QuantityBlock
QuantityBlock  ::= '{' 'value' Value 'unit' Value
                     [ 'kind' Value ] [ 'uncertainty' Value ]
                     [ 'tolerance' Value ] '}'
Applicability  ::= 'applicability' '{' ApplicabilityEntry { ApplicabilityEntry } '}'
ApplicabilityEntry ::= DimensionKey ':' Value [ 'match' MatchMode ]
            (* Value: a bare id, a quoted text, a bracket list, or a
               parameter-mapping block *)
MatchMode    ::= 'any' | 'all' | 'exact'   (* parse-enforced *)
TrustRef       ::= 'trust_ref' BareToken [ 'key' BareToken ]
            (* the organization identifier, optionally one published key *)
CorrespondsEntry ::= 'corresponds' BareToken QuotedString [ CorrespondsBlock ]
CorrespondsBlock ::= '{' { 'projection' BareToken ProjectionPayload } '}'
ProjectionPayload ::= '{' { BareToken Value } '}'
            (* the codec's steering input, stored untyped *)
AliasListEntry ::= AliasKeyword [ SpellingCode ] '{' { Value } '}'
AliasKeyword   ::= 'aliases' | 'alt' | 'colloquial' | 'abbreviations'
                 | 'deprecated'
            (* the term's alias family; the tagged form carries the
               spelling its list is authored in *)
SpellingCode   ::= BareToken   (* ISO 24229 code; C89 *)

DescriptionBlock ::= 'description' Block
            (* THE PROSE QUARANTINE (C158): human-language text appears
               only here, or in a label facet. Every other string field
               of every construct is useable data — a name, a unit, a
               code, an expression, or a urn. The deletion test: a
               package with all description blocks removed parses,
               checks, links, runs, and attests identically. *)

ExpressionCarrier ::= CarrierKeyword Block
CarrierKeyword ::= 'expression' | 'derive' | 'derivation' | 'check'
                 | 'args'
            (* the v3.3 expression carriers (11.1.4): inside any
               construct's item stream, a carrier keyword followed by a
               block is the key's block value — the explicit exception
               to the construct reservation; a carrier keyword followed
               by a bare token still heads a construct *)
ConformanceTestKeyword ::= 'conformance_test' | 'conformance test'
            (* the corpus spells the space form; one keyword, two
               spellings *)

MappingBlock   ::= 'mapping' Format Identifier Block
Format         ::= 'xml' | 'yaml' | 'json' | 'toml' | 'csv'
            (* the declared wire form of one class for one format;
               clause 16. The block's facets are the LML surface:
               element, namespace, map_element, map_attribute,
               map_content, mixed_content, map, map_key, map_value,
               render_nil. *)
MemberFieldsBlock ::= 'member_fields' '{' { FieldDecl } '}'
            (* the typed payload schema shared by an enum's members;
               clause 10.14 *)
StringFormatBlock ::= 'string_format' ':' BareToken Block
            (* the grammar-backed string form of a class: artifact +
               root; clause 10.15 *)
NamespaceBlock ::= 'namespace' Identifier Block
            (* uri + prefix (+ optional default marker); clause 9.6 *)
----
EOF

=== The expression grammar

The inline carriers' body is the language's own expression syntax — a
precedence grammar over the tokens of <<lexical-grammar>>, one
expression per carrier, harvested by the checker's identifier
resolution (<<checker,16>>):

[source,ebnf]
----
Expression   ::= ImpliesExpr
ImpliesExpr  ::= OrExpr { 'implies' OrExpr }
OrExpr       ::= XorExpr { 'or' XorExpr }
XorExpr      ::= AndExpr { 'xor' AndExpr }
AndExpr      ::= CompareExpr { 'and' CompareExpr }
CompareExpr  ::= AddExpr { ('=' | '!=' | '≠' | '<' | '>' | '<=' | '>=') AddExpr }
AddExpr      ::= MulExpr { ('+' | '-') MulExpr }
MulExpr      ::= Unary { ('*' | '/') Unary }
Unary        ::= [ 'not' | '-' ] Primary
Primary      ::= Number | String | 'true' | 'false'
               | '(' Expression ')'
               | PathOrCall
               | Navigation
               | Conditional
PathOrCall   ::= DottedPath [ '(' [ Expression { ',' Expression } ] ')' ]
DottedPath   ::= BareToken { '.' BareToken }
Navigation   ::= DottedPath '->' Iterator '(' BareToken '|' Expression ')'
Iterator     ::= 'forAll' | 'exists' | 'select' | 'collect'
Conditional  ::= 'if' Expression 'then' Expression 'else' Expression 'endif'
----

The precedence is the listing's order: `implies` binds loosest, the
arithmetic tightest; every binary level is left-associative. The
conditional's `endif` delimits, so a branch needs no parentheses at any
precedence — a branch may itself be a conditional. The navigation's
lambda parameter scopes its body exactly like a limit's `args` binding
(<<limit-expressions,11.1.4>>). The iterators' values: `forAll` and
`exists` yield booleans; `select` yields a subcollection of its source;
`collect` projects — a collection of the body's element kind. The
boolean literals are kindless leaves. The same grammar is implemented a
second time, independently, by the conformance suite's second checker
(conformance/checker2-rules.json): the two implementations agreeing is
the grammar's conformance proof.

=== What the grammar does not decide

Three judgments are deliberately not grammar:

. *closed vocabularies.* Where a facet's value set is closed, the clause
that specifies the facet says so, and says whether the set is
parse-enforced (a violation is a parse error) or checker-enforced (a rule
of Annex B);
. *reference resolution.* Whether an identifier resolves is a checker
matter (Annex B), never a parse matter;
. *scope discipline.* Which slot a value may occupy at which chain level
is a checker matter (C17), never a parse matter.
